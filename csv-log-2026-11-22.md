## Approach

Read the reference (`baselines/csv-reader/vendor/csv-reader/index.js`,
csv-reader 1.0.0) to learn the exact semantics, then wrote a fresh
single-pass parser:

- Unquoted fields scanned with `charCodeAt`, taken out with a single
  `slice` once the end is found.
- Quoted fields jump straight to the next quote with `indexOf`.
- Field readers write their result into shared variables instead of
  allocating a result object per field (~710k fields on the practice set),
  which keeps garbage collection low.
- Doubled quotes, CR/LF inside quotes, junk after a closing quote and
  stray CRs handled only on paths that run when such a thing appears.
- `main.ts` written fresh with the same behaviour as the baseline driver:
  `setFlagsFromString('--no-incremental-marking')` from `node:v8` before
  importing `solve.js`; reads `MAKEFUN_INPUT_DIR/cases.json`, answers each
  case with `run()`, writes `MAKEFUN_OUTPUT_DIR/answers.json`.

Optimisation attempts measured and kept/dropped:

- `indexOf` (3 calls) for unquoted fields: SLOWER than the `charCodeAt`
  loop on short fields (isolated `run()` 375 ms vs 244 ms) — dropped for
  unquoted, kept only for quoted fields.
- `indexOf` fast path for quoted fields: isolated `run()` 244 ms -> ~175 ms
  — kept.
- Shared-variable field results instead of per-field objects: isolated
  `run()` ~175 ms -> ~98 ms — kept.

## 3. Edge-case checks: 57/57

Compared `run()` against the reference `readCsv` on 57 hand-written
inputs (`/tmp/csv-edge.mjs`). All pass. Covered:

- BOM at start (dropped) and BOM mid-text (kept); empty text (header
  true -> columns `[]`, header false -> columns `null`).
- CRLF, LF-only, lone CR outside quotes (stray_cr), a line holding only
  stray CRs (no record, errors stay), stray CR at end of text, single
  stray-CR text.
- Empty lines (LF and CRLF), trailing newline, no trailing newline.
- Quoted fields with commas, `""` escapes, a field starting with `""`,
  empty quoted field, a record that is just `""`, `"`, `"""`, `""""`.
- CRLF, lone CR and LF inside quotes (each read as LF, line counted).
- quote_junk after a closing quote (with/without following comma, at EOF,
  lone CR at EOF after the quote), CRLF after a closing quote, quoted
  field then stray CR then comma.
- Unterminated quote (literal quote, rest re-read unquoted), unterminated
  at EOF, unterminated with stray CR and with a newline inside.
- Quote inside an unquoted field (literal).
- Short rows (padded, `fields` = its count) and long rows (cut, `extra` =
  the cut fields), header vs no-header, single column, just a comma,
  comma at end of record, empty field in the middle.
- Line numbers across a quoted newline, short row after a quoted newline,
  multiple errors in one record.
- Unicode, surrogate pairs, BOM + unterminated quote.
